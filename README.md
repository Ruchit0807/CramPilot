# CramPilot

CramPilot is an AI-powered exam survival operating system for university students.

The platform helps students prepare for exams in 24–48 hours using:
- AI workflow orchestration
- professor-aware strategies
- intelligent topic prioritization
- emergency study roadmaps
- prompt generation
- multi-AI learning workflows

## Features

- Dynamic exam strategy generation
- Professor intelligence system
- Emergency cram mode
- Multi-AI workflow recommendations
- Personalized study roadmaps
- Survivability scoring
- Revision workflows
- Flashcard recommendations

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Zustand
- Framer Motion
- shadcn/ui

## Status

Frontend MVP in active development.

## Vision

CramPilot aims to become an intelligent AI-native academic operating system optimized for high-pressure exam preparation.
